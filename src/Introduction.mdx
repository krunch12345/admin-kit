# admin-kit

Shared admin panel kit for React apps: auth, layout, shell, pages, and reusable MUI UI.

Use the sidebar to open a component. Stories under **Pages**, **Shell**, and **UI** show interactive examples; open **Docs** on a component for props and usage notes.

## What’s inside

- **Pages** — ready-made screens (Login, Account, Main, …)
- **Shell** — header, drawer, footer, menu pieces
- **UI** — form controls, upload, modals, lists, and other building blocks

## In your app

```js
import { Content, createAdminBaseQuery } from 'admin-kit'
import { TextField } from 'admin-kit/ui'
```

Peer dependencies and install notes are in the package README. Live catalog: [krunch12345.github.io/admin-kit](https://krunch12345.github.io/admin-kit/).
